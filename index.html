Flow Policy Gradients for Robot Control

Brent Yi1, Hongsuk Choi1, Himanshu Gaurav Singh1, Xiaoyu Huang1, Takara E. Truong1, Carmelo Sferrazza1, Yi Ma1, Yan Duan1, Pieter Abbeel1, Guanya Shi1, Karen Liu1, Angjoo Kanazawa1

Abstract

Iterative, flow-based action distributions promise flexibility and expressivity for robot policy learning.Intractable likelihoods, however, make them difficult to train using standard reinforcement learning algorithms. In this work, we show how flow policies trained via reinforcement learning can be made practical using the likelihood-free flow policy gradient framework. We find that naive flow policy gradient implementations can be unstable to train for real-world robot control problems, but that these challenges can be overcome with an updated objective that reduces gradient variance and better preserves policy entropy. Experiments in robot locomotion, humanoid motion tracking, and manipulation show how our updated algorithm improves flow policy training, how the expressivity of flow policies facilitates exploration, how policies can be directly deployed to real robots, and how our contributions apply both to learning from scratch and to finetuning.
